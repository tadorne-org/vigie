# Vigie

Un nœud d'énergie toujours vivant pour petits voiliers : une carte qui mesure
la batterie, veille tout l'hiver et rend compte depuis la cale. Un projet
[Tadorne](https://tadorne.org/).

Site du projet : <https://vigie.tadorne.org/>

**Vigie** is the energy node board: an ESP32 and an INA226 that measure a small sailboat's battery, upstream of the main switch, down to a few microamps — enough to last a whole winter layup without draining the battery.

Vigie 1.0 is arriving on the bench. A few boards will be assembled beyond what the boat needs. Before turning it into a product — and before taking on the conformity work that selling imposes — one question remains: **does this object interest anyone other than its author?**

This page exists to answer that. It sells nothing.

{{< callout title="What this page is not" >}}
- It is **not a pre-order**: no payment, no commitment, no promised date.
- It is **not a reservation**: the number of boards available is not known yet.
- It is **not a form**: the message is sent from the visitor's own mail client. No script, no cookie, no data passed to a third party — as everywhere on this site.
{{< /callout >}}

## Answering

The link below opens a pre-filled message. Six lines are enough. The message goes straight from your mail client to `contact@tadorne.org`; nothing passes through the site.

If the link does not open, write to `contact@tadorne.org` with these six lines:

1. Boat — model, length
2. Home port and sailing area
3. Current installation — battery, charge, shunt if any
4. What would interest you — board only, kit (board + shunt + spacers), or simply following the project
5. Wintering aboard — yes or no
6. Preferred documentation language — English or French

## What happens next

Every message gets an answer. People on this list are told first if a small batch goes ahead, and before any public announcement.

Replies are used only to decide what the project does next. They are neither sold nor shared, and a single message is enough to have them deleted.

Progress is kept up to date in [the roadmap](/roadmap/) and [the log](/log/).
